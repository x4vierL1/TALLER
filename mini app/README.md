# Mini App de Usuarios

## Descripción

Este proyecto es una mini aplicación web desarrollada con HTML, CSS y JavaScript.

La aplicación obtiene información de usuarios mediante una API pública y muestra los datos dinámicamente en pantalla.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- JSONPlaceholder
- ESLint
- Husky
- Git

## Funcionalidades

- Obtener usuarios desde una API pública.
- Mostrar los usuarios dinámicamente.
- Buscar usuarios por nombre, usuario o correo electrónico.
- Enlaces a los sitios web de los usuarios.
- Validación del código mediante ESLint.
- Ejecución automática de ESLint antes de cada commit mediante Husky.

## API utilizada

JSONPlaceholder:

https://jsonplaceholder.typicode.com/users
